# CareerPilot

CareerPilot 是一个基于大语言模型的大学生职业成长与求职陪跑平台，面向大一到大四学生，覆盖用户画像、职业规划、能力差距分析、简历素材沉淀、JD 匹配与模拟面试等完整成长求职流程。

## 项目结构

```text
CareerPilot/
├── AI_CareerPilot_Project_Guide.md
├── career-pilot-frontend/
└── career-pilot-backend/
```

## MVP 模块

1. 用户登录与注册
2. 用户画像采集
3. AI 职业规划
4. 能力差距分析
5. 简历素材库
6. JD 匹配与简历优化
7. AI 模拟面试
